Section C — Borrowing Rules & Reference Scopes

One mutable OR many immutable; references must be valid; reference scope ends at last use.

}
Answer:
B — an immutable reference exists while creating a mutable reference.

9) Does this compile? (Think: “scope ends at last use”)

Auto 
fn main() {
    let mut s = String::from("Hello");
    let view = &s;
    println!("view: {view}");
    let edit = &mut s;
    edit.push_str("!");
    println!("{s}");
}
Answer:
A — notes: a reference’s scope ends at its last use, so after the println, the immutable borrow is effectively over.

20) Does this compile? (slice + clear)

Auto 
fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}

fn main() {
    let mut s = String::from("Hi there");
    let w = first_word(&s);
    s.clear();
    println!("w: {w}");
}
Answer:
B — slices don’t take ownership; they’re references, so modifying the string while the slice exists breaks the rules (reference must remain valid).
